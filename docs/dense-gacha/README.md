# DENSE クーポンガチャ（お試し版）

公式LINEの代わりに、Instagramストーリーズから開くURLで「ニックネームを入れてガチャを回す → 当たり券をスクショして来店」を実現するブラウザアプリの試作です。

- 公開中のお試しページ: https://claude.ai/artifact/XSbYWe639TRU9E1kj7eGtF （`#admin` を付けると管理画面）
- `dense-gacha.html` — 単体で開ける版。ブラウザでそのまま開くと「この端末だけに保存」モードで全機能を試せます（管理画面PIN 初期値 2525）
- `dense-gacha.artifact.html` — claude.ai Artifact として公開しているソース（共有データ付き）

## 仕組み

| 画面 | できること |
|---|---|
| ガチャ画面（お客さん） | ニックネーム入力 → ガチャ → 当たり券（景品・ニックネーム・日時・確認コード）。1人1日1回。店舗状況は一切見えない |
| 管理画面 `#admin`（店舗） | 今日の予約組数・現在の来客・いつもの来客・天気を入力 → 「強め／ふつう／控えめ／停止」を自動判定。手動切替も可。景品ごとの重みと1日の上限、結果ログ（誰に何が出たか・使用済みチェック）、URLコピー |

- 確認コードは `ニックネーム＋日時＋景品＋シークレット` から生成した6文字。管理画面のログと照合できるので、スクショの加工では通りません
- 大当たり（焼酎ボトル・テキーラ30杯）は1営業日の上限枚数を超えると出ません。全体の配布上限も設定できます
- 営業日は朝6時で切り替わります（深夜営業対応）

## 本番運用に向けて

claude.ai の Artifact はログインした人しか共有データに書き込めないため、不特定のお客さんが回す本番は、この HTML をそのまま Vercel などに置き、保存先を Supabase に差し替える構成が必要です（このリポジトリの LINE Bot と同じ基盤）。
